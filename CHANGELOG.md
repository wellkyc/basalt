# Changelog

## 0.1.0

First release.

- QBasic-style syntax: `IF`, `FOR`, `WHILE`, `DO`, `SELECT CASE`, `SUB`, `FUNCTION`, `GOTO`, `GOSUB`, line numbers
- numbers, strings, booleans, arrays, `CONST`, `DATA` / `READ`
- `CLS`, `COLOR`, `LOCATE`, `SLEEP` for terminal programs
- 34 built-in functions
- REPL with multi-line blocks
- errors with line, column and a caret under the problem
- prebuilt binaries for Windows, Linux and macOS, install scripts
